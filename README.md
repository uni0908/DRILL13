# 아이템 모드 게임

Python과 pico2d를 사용하는 게임이다. Windows의 Consolas 글꼴을 사용한다.
프로젝트 폴더에서 실행한다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

타이틀에서 스페이스바로 시작한다. 방향키로 이동하고 스페이스바로 공을
발사한다. 수면 상태에서는 스페이스바로 먼저 깨어난다.

- `I`: 아이템 창 열기/닫기. 창이 열려도 게임은 계속 진행된다.
- 창 안에서 `0`: 발사 해제. 이미 발사한 공은 유지된다.
- 창 안에서 `1` / `2`: 이후 발사할 공을 21×21 / 41×41로 선택한다.
- `P`: 일시정지/복귀.
- `Esc`: 플레이에서 타이틀로 돌아간다.

새 게임은 21×21 공으로 시작한다. 숫자 키는 창이 열려 있을 때만 적용되며,
0·1·2로 선택하면 아이템 창이 자동으로 닫힌다.

검증은 실제 pico2d 캔버스를 열고 입력 이벤트를 주입하는 통합 검사다.

```powershell
python -m unittest -v test_item_mode
```

검사 범위: 열린 창에서 이동·애니메이션·수면·공 이동 및 제거, 선택 변경과
발사 해제, 기존 공 크기 유지, P 복귀, 새 게임 초기화, 종료 이벤트.
우측 상단 패널과 공 크기는 실제 렌더링 화면으로도 확인했다.

이전 에이전트 실행 환경에서 Python 접근 오류가 있었으나, 이를 Python이
삭제된 것으로 단정한 설명은 잘못되었다. 사용자 확인에 따르면 샌드박스
제한으로 인한 문제이며, Python 재설치는 필요하지 않다.
아이템 선택 시 자동 닫기 변경은 사용자 요청에 따라 실행·테스트하지 않았다.
